About this project

This learning project combines incident management with a small machine-learning model. Users can record a service or application issue, describe what happened, and choose its severity.

When an incident is submitted, the application saves it and sends its description to a text-classification model. The model uses TF-IDF to turn text into features and Multinomial Naive Bayes to estimate whether the incident may be impactful. The dashboard displays the result and the model's estimated impact probability.

This model is trained on a small synthetic dataset, so its predictions are only for learning and demonstration. They should not be used to make real production decisions. If prediction is unavailable, the incident is still saved for handling.
